# Fuel Logger — แผนงาน

อัปเดตล่าสุด: 15 ต.ค. 2569

## ⭐ ทำต่อเป็นอันดับแรก

- [ ] **แจ้งเตือนราคาน้ำมันพรุ่งนี้**
  ใช้ API บางจาก (`oil-price.bangchak.co.th/ApiOilPrice2/th`) ที่มี `PriceTomorrow` ดึงผ่าน Apps Script
  (เพราะเรียกตรงจากแอปไม่ได้ ติด CORS) แล้วแสดงบนหน้าแรก เช่น "พรุ่งนี้ E20 ขึ้น 0.30 บาท เติมวันนี้ประหยัดกว่า"
- [ ] **แก้ไขรายการได้** (ทั้งเติมน้ำมันและค่าใช้จ่ายอื่น) แทนการลบแล้วบันทึกใหม่
  ต้องเพิ่ม action `update` / `updateExpense` ใน Apps Script และตรวจแถวแบบเดียวกับการลบ (เทียบเลขไมล์/ยอดเงิน)
- [ ] **เพิ่มวันครบกำหนดลงปฏิทิน iPhone** (ภาษี, ประกัน, พ.ร.บ., นัดเช็กระยะ, ค่างวด)
  สร้างไฟล์ `.ics` พร้อมตั้งเตือนล่วงหน้า → ได้การแจ้งเตือนจริงของ iOS แม้ไม่เปิดแอป

## ใช้งานทุกวัน

- [ ] **จำที่จอดรถ** — บันทึกตำแหน่ง GPS + ถ่ายรูปเสา/ชั้นจอด แล้วกดนำทางกลับได้
- [ ] **งบน้ำมันรายเดือน** — ตั้งงบ แสดง % ที่ใช้ไปบนหน้าแรก เตือนเมื่อใกล้เกิน
- [ ] **ปุ่มโทรฉุกเฉิน** — ศูนย์ประกัน, รถยก, ศูนย์ Toyota + เลขกรมธรรม์ให้คัดลอก
- [ ] **กระเป๋าเอกสารรถ** — รูปเล่มทะเบียน, กรมธรรม์, พ.ร.บ. (เก็บใน Google Drive ผ่าน Apps Script)

## ดูแลรถ

- [ ] **อายุชิ้นส่วนสิ้นเปลือง** — ยาง, แบตเตอรี่, ใบปัดน้ำฝน, ผ้าเบรก (นับจากเลขไมล์/วันที่เปลี่ยน) แสดงเป็นหลอด %
- [ ] **เตือนเช็กลมยางทุกเดือน** พร้อมค่าลมยางมาตรฐาน Yaris ATIV
- [ ] **แนะนำวันล้างรถ** จากพยากรณ์อากาศ (ฝนจะตกใน 2–3 วัน → รอก่อน)
- [ ] **ต้นทุนรถทั้งหมดต่อกิโลเมตร** — น้ำมัน + ค่างวด + ประกัน + ภาษี + ซ่อม

## การเดินทาง

- [ ] **บันทึกทริป** — เลขไมล์เริ่ม/จบ แล้วรวมค่าน้ำมัน ทางด่วน ที่จอดของทริป
- [ ] **หารค่าน้ำมันกับเพื่อน** — ใส่จำนวนคน แล้วคำนวณคนละเท่าไร
- [ ] **สถิติปั๊มที่เติม** — บันทึกตำแหน่งตอนเติม แล้วสรุปปั๊มที่เติมบ่อย/ปั๊มที่ได้อัตราดีกว่า

## วิเคราะห์ / สนุก

- [ ] **กราฟราคาน้ำมันที่จ่ายจริง** เทียบกับราคา PTT
- [ ] **คำนวณปิดหนี้ก่อนกำหนด** — โปะ X บาท ผ่อนหมดเร็วขึ้นกี่เดือน (ต้องรู้อัตราดอกเบี้ย)
- [ ] **สถิติส่วนตัว / เหรียญรางวัล** — ถังที่ประหยัดที่สุด, ครบ 30,000 กม., เติมครบ 100 ครั้ง
- [ ] **การ์ดสรุปรายปีแบบแชร์ได้** (บันทึกเป็นรูปแบบ Spotify Wrapped)
- [ ] **เทียบกับรถไฟฟ้า** — ถ้าเป็น EV ปีนี้จะจ่ายค่าไฟเท่าไร
- [ ] **สำรองข้อมูล** — ส่งออก CSV / Excel ปุ่มเดียว

## ไว้ทีหลัง

- [ ] **Widget บนหน้าจอโฮม** ผ่านแอป Scriptable (ขนาดเล็ก / กลาง / หน้าจอล็อก)
  ข้อจำกัด: iOS รีเฟรชเอง 15–60 นาที, แตะแล้วเปิด PWA ตรง ๆ ไม่ได้ (จะเปิดใน Safari แทน)
- [ ] **Siri Shortcut** — "Hey Siri เติมน้ำมัน" → ถามเลขไมล์ + ยอดเงิน → บันทึกลง Sheet ผ่าน Apps Script เดิม
  ใช้กับ Action Button / Back Tap ได้
- [ ] **ประมาณระยะที่วิ่งได้ให้แม่นขึ้น** — ตอนนี้ใช้ค่ากลางระยะต่อถัง 1 ปี (~384 กม.) ลบระยะที่น่าจะวิ่งไปแล้ว
  (ค่าเฉลี่ย ~39 กม./วัน หรือจากเลขไมล์ที่อัปเดตเอง) ข้อมูลสไตล์การขับที่ผู้ใช้เล่ามายังไม่ตรงกับระยะจริงใน Sheet
  (คำนวณได้ ~6,300 กม./ปี แต่จริง ~13,000 กม./ปี) — รอหาวิธีใหม่

## ⚠️ ค้างตรวจสอบกับเจ้าของรถ

- [ ] **ชีต Car installment มีงวดผ่อน 49 แถว** (พ.ย. 67 – พ.ย. 71) ไม่รวมเงินดาวน์ → แอปแสดง 24/49 = 49%
  ถ้าสัญญาจริง 48 งวด ให้ลบแถวที่เกินใน Sheet แล้วแอปจะแสดง 50% เอง
- [ ] **การตั้งค่าเช็กระยะ** ตั้ง "เช็กครั้งล่าสุดที่ 30,000 กม." ทั้งที่เลขไมล์ยังไม่ถึง
  ถ้าตั้งใจหมายถึงนัดครั้งถัดไป ให้แก้เป็นเลขไมล์ครั้งล่าสุดจริง หรือบันทึกนัดเป็นค่าใช้จ่ายหมวดเช็กระยะล่วงหน้า
